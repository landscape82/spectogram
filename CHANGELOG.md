# Changelog

Release notes for each tagged version are generated automatically from commit history and published to the project's [GitHub Releases](https://github.com/landscape82/spectogram/releases) page by [`.github/workflows/release.yml`](.github/workflows/release.yml).

To cut a release, push a tag matching `vX.Y.Z`:

```bash
git tag v0.1.0
git push origin v0.1.0
```
